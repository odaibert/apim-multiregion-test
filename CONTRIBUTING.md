# Contributing to APIM Multi-Region Failover Demo

Thank you for your interest in contributing! This project is an educational demo for Azure API Management multi-region failover scenarios.

## How to Contribute

1. **Fork** the repository
2. **Create a branch** for your feature or fix: `git checkout -b feature/my-change`
3. **Make your changes** and test them
4. **Commit** with a clear message: `git commit -m "Add: description of change"`
5. **Push** to your fork: `git push origin feature/my-change`
6. **Open a Pull Request** against `main`

## Guidelines

- Keep the notebook self-contained — users should be able to click **Run All**
- Use Bicep for all infrastructure-as-code (no ARM JSON)
- Test changes by running the full notebook end-to-end
- Update documentation (README, notebook markdown cells) when changing behavior
- Follow existing code style and patterns

## Reporting Issues

- Use [GitHub Issues](../../issues) to report bugs or suggest features
- Include the error output and which notebook cell failed
- Mention your Azure CLI version (`az version`) and Python version

## Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to uphold this code.
